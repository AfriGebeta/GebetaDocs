## **Overview**
<br/>

Tiles API is a tool that allows you to create and manage interactive map tiles in your applications. With comprehensive local data coverage and fine-tuned customization options, you can build beautiful, performant maps for web and mobile platforms.

We currently support JavaScript and Flutter SDKs for web and mobile, making it easy to integrate maps into your projects.

## **Key Features**
<br/>

- **Comprehensive Map Tiles**: Access detailed map tiles with rich local data coverage

- **Fine-tune Customizable Styles**: Customize map appearance to match your brand and design requirements

- **Interactive Markers**: Support for fully customizable, interactive markers with rich content

- **Polylines, Polygons, and Circles**: Draw routes, areas, and zones with custom styling

- **Built-in Customizable Marker Clustering**: Intelligent marker clustering for better performance and UX

- **High Performance**: Optimized tile delivery for smooth map interactions

## **SDKs & Integration**

<br/>

Choose your platform to get started:
<br/>

### **Web**
- [JavaScript SDK](/docs/tiles/js) - Use `@gebeta/js` for vanilla maps or `@gebeta/react` for React apps

### **Mobile**
- [JavaScript SDK](/docs/tiles/js) - For React Native apps
- [Flutter SDK](/docs/tiles/flutter) - Native Flutter widgets for iOS and Android

## **Getting Started**

<br/>

1. **Choose Your SDK**: Select JavaScript for web or mobile, or Flutter for mobile development

2. **Install the Package**: Follow the installation guide for your chosen SDK

3. **Configure Your Map**: Set up your map with custom styles and features

4. **Add Interactivity**: Implement markers, overlays, and user interactions

5. **Deploy**: Launch your map-powered application
