# ONM API

ONM (one to many) measures the trip from a single origin to several destinations at once. For each destination you get the road distance and travel time, so you can pick the closest one by road rather than by straight-line distance. To draw the route to the one you pick, call the [Direction API](/direction).

## When to use it

  <Card icon={<TargetIcon />} title="Nearest place">
    Find the closest hospital, branch or fuel station a user can actually drive to.
  </Card>
  <Card icon={<PaperPlaneIcon />} title="Dispatch">

  </Card>
  <Card icon={<MixerHorizontalIcon />} title="Ranking options">

  </Card>

  </Card>
</Cards>

For distances between every pair of points, not just from one origin, use the [Matrix API](/matrix).

## Request

```bash
GET https://mapapi.gebeta.app/api/route/onm/?origin={lat,lng}&json=[{lat,lng},{lat,lng}]&apiKey={your-api-key}
```

| Parameter | Type     | Required | Description                                              |
| --------- | -------- | -------- | -------------------------------------------------------- |
| `origin`  | `string` | Yes      | Where every route starts, as `{lat,lng}`.                |
| `json`    | `string` | Yes      | The destinations, as `[{lat,lng},{lat,lng},…]`. Up to 5. |
| `apiKey`  | `string` | Yes      | Your Gebeta Maps API key.                                |

## Response

`origin_to_destination` has one entry per destination. `to` is the destination's position in the `json` list you sent.

```json
{
  "origins": [{ "lat": 9.052066, "lon": 38.710815, "radius": null }],
  "destinations": [
    { "lat": 9.04128, "lon": 38.721692, "radius": null },
    { "lat": 9.048567, "lon": 38.73236, "radius": null }
  ],
  "origin_to_destination": [
    { "from": 0, "to": 0, "distance": 4.008, "time": 611 },
    { "from": 0, "to": 1, "distance": 4.164, "time": 719 }
  ]
}
```

| Field                              | Description                                                         |
| ---------------------------------- | ------------------------------------------------------------------- |
| `origins`                          | The origin, snapped to the nearest road, as `lat` and `lon`.        |
| `destinations`                     | The destinations, snapped the same way, in the order you sent them. |
| `origin_to_destination[].to`       | Position of the destination in the list you sent.                   |
| `origin_to_destination[].distance` | Road distance in kilometers.                                        |
| `origin_to_destination[].time`     | Travel time in seconds.                                             |

In this example, the first destination is the closer one by road: 611 seconds (about 10 minutes) against 719.

## Errors

| Status | Message                          | What to do                                                           |
| ------ | -------------------------------- | -------------------------------------------------------------------- |
| `401`  | `Not Authorized - No Token`      | Add your API key as the `apiKey` parameter.                          |
| `401`  | `Not Authorized - Invalid Token` | The key is wrong or expired. Copy a current key from your dashboard. |
| `404`  | `NoRoute`                        | A destination can't be reached by road from the origin.              |
| `422`  | `InvalidInput`                   | Check that `origin` is `{lat,lng}` and `json` is `[{lat,lng},…]`.    |

```json
{
  "error": {
    "additional": null,
    "code": "A_ERR00004",
    "message": "Invalid access token!",
    "status": 401
  }
}
```

## Limits

- **Destinations:** Up to 5 per request.
- **Rate:** 50 requests per second per API key. Requests above that are rejected, so throttle or batch them.
- **Countries:** The origin and all destinations must be in the same country.
