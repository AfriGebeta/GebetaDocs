# Place Validation API

Addresses typed by people are messy, and in Ethiopia the official names of sub-cities and woredas vary between sources. The Place Validation API checks an address one level at a time, from country down to district. For each level it tells you whether the place exists, whether it really sits inside the level above, and how confident the match is.

## How it decides

<Cards>
  <Card icon={<MagnifyingGlassIcon />} title="Fuzzy matching">
    Each name is compared by spelling and sound, so `Bole` and `bolle` can both match.
  </Card>
  <Card icon={<LayersIcon />} title="Parent checks">
    A level is only valid if it belongs to its parent. A woreda that exists but sits in a different
    sub-city is marked invalid.
  </Card>
  <Card icon={<CheckCircledIcon />} title="Confidence">
    Every level gets `high`, `medium` or `low` confidence, so you can accept close matches instead
    of rejecting a correct address over a typo.
  </Card>
</Cards>

## When to use it

<Cards>
  <Card icon={<Pencil2Icon />} title="Checkout and signup forms">
    Catch mistakes in an address before you save it.
  </Card>
  <Card icon={<FileTextIcon />} title="Cleaning records">
    Standardize addresses already in your database.
  </Card>
  <Card icon={<EyeOpenIcon />} title="Review queues">
    Accept `high` matches automatically and send `low` ones to a person.
  </Card>
</Cards>

## Request

```bash
POST https://mapapi.gebeta.app/api/v1/place/validation
Content-Type: application/json
```

Send as many levels as you have, from the top down.

| Field          | Description                                      |
| -------------- | ------------------------------------------------ |
| `country`      | Country, such as `Ethiopia`.                     |
| `province`     | Region or chartered city, such as `Addis Ababa`. |
| `county`       | County, such as `Addis Ababa`.                   |
| `municipality` | City or town.                                    |
| `borough`      | Sub-city, such as `Bole`.                        |
| `district`     | Woreda, such as `woreda 14`.                     |
| `village`      | Village.                                         |

## Example

```bash
curl -X POST "https://mapapi.gebeta.app/api/v1/place/validation" \
  -H "Content-Type: application/json" \
  -d '{
    "country": "Ethiopia",
    "province": "Addis Ababa",
    "county": "Addis Ababa",
    "municipality": "Addis Ababa",
    "borough": "Bole",
    "district": "woreda 14"
  }'
```

## Response

```json
{
  "valid": false,
  "levels": {
    "country": { "valid": true, "confidence": "high" },
    "province": { "valid": true, "confidence": "high" },
    "county": { "valid": true, "confidence": "high" },
    "municipality": { "valid": true, "confidence": "high" },
    "borough": { "valid": true, "confidence": "high" },
    "district": { "valid": false, "confidence": "low" },
    "village": { "valid": false, "confidence": "" }
  }
}
```

`valid` at the top is `true` only when every level you sent is valid. In this example the woreda didn't match inside Bole, so the address as a whole is invalid. `village` wasn't sent, so its confidence is empty.

| Confidence | Meaning                                                                       |
| ---------- | ----------------------------------------------------------------------------- |
| `high`     | A close match, with little or no difference from our data.                    |
| `medium`   | A probable match, with small spelling differences or a recently changed name. |
| `low`      | A weak match. Ask the user to check it, or review it by hand.                 |

<Callout title="Woredas can come back medium">
  Some woreda boundaries and names have changed recently, so a correctly spelled woreda can still
  return `medium`. Treat `medium` as a match unless you need to be strict.
</Callout>

## Limits

- **Rate:** 50 requests per second per API key. Requests above that are rejected, so throttle or batch them.
