# Direction API

The Direction API returns the best driving route from an origin to a destination, optionally through stops along the way. You get the travel time, the total distance and the route as a list of coordinates you can draw on a map, plus other possible routes if you ask for them.

## Request

```bash
GET https://mapapi.gebeta.app/api/route/direction/?origin={lat,lng}&destination={lat,lng}&apiKey={your-api-key}
```

| Parameter     | Type     | Required | Description                                                                                       |
| ------------- | -------- | -------- | ------------------------------------------------------------------------------------------------- |
| `origin`      | `string` | Yes      | Where the route starts, as `{lat,lng}`.                                                           |
| `destination` | `string` | Yes      | Where the route ends, as `{lat,lng}`.                                                             |
| `apiKey`      | `string` | Yes      | Your Gebeta Maps API key.                                                                         |
| `waypoints`   | `string` | No       | Stops to pass through in order, as `[{lat,lng},{lat,lng},…]`. Up to 10.                            |
| `alternative` | `string` | No       | Set to `t` to also get other possible routes, in `alternates`.                                    |

## Response

```json
{
  "msg": "Ok",
  "timetaken": 1275.631,
  "totalDistance": 8895,
  "direction": [
    [9.055978, 38.704943],
    [9.056214, 38.704691]
  ]
}
```

| Field           | Description                                                                                          |
| --------------- | ---------------------------------------------------------------------------------------------------- |
| `msg`           | `Ok` when a route was found.                                                                         |
| `timetaken`     | Travel time for the whole route, in seconds.                                                         |
| `totalDistance` | Length of the whole route, in meters.                                                                |
| `direction`     | The route as `[lat, lng]` points, in order. Draw them as a line on a map. A real response has hundreds of points; this example shows the first two. |

### Alternative routes

With `alternative=t`, the response also has `alternates`: other routes between the same points, each with its own time, distance and line.

```json
{
  "msg": "Ok",
  "timetaken": 1275.631,
  "totalDistance": 8895,
  "direction": [[9.055978, 38.704943]],
  "alternates": [
    { "timetaken": 1182.037, "totalDistance": 8425, "direction": [[9.055978, 38.704943]] },
    { "timetaken": 1404.338, "totalDistance": 10585, "direction": [[9.055978, 38.704943]] }
  ]
}
```

An alternate can be quicker than the main route, as the first one is here, so compare `timetaken` if you want the fastest.

## Errors

| Status | Message                          | What to do                                                           |
| ------ | -------------------------------- | -------------------------------------------------------------------- |
| `401`  | `Not Authorized - No Token`      | Add your API key as the `apiKey` parameter.                          |
| `401`  | `Not Authorized - Invalid Token` | The key is wrong or expired. Copy a current key from your dashboard. |
| `404`  | `NoRoute`                        | There's no road between the points. Check they're reachable by car.  |
| `422`  | `InvalidInput`                   | Check that `origin`, `destination` and `waypoints` use `{lat,lng}`.  |

Errors come back in this shape:

```json
{
  "error": {
    "additional": null,
    "code": "A_ERR00004",
    "message": "Invalid access token!",
    "status": 401
  }
}
```

## Limits

- **Rate:** 50 requests per second per API key. Requests above that are rejected, so throttle them or spread traffic across keys for different apps.
- **Waypoints:** Up to 10 per request.
