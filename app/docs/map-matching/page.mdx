# Map Matching API

GPS points drift. A phone in a moving car can report positions in buildings, on the wrong side of the road or off the road entirely. The Map Matching API takes a trace of GPS points, works out which roads were most likely driven, and returns a clean path along them with its total distance.

## When to use it

<Cards>
  <Card icon={<MagicWandIcon />} title="Cleaning traces">
    Remove drift from tracking data before you show it or store it.
  </Card>
  <Card icon={<CounterClockwiseClockIcon />} title="Rebuilding trips">
    Reconstruct the route a delivery or service vehicle took from its GPS log.
  </Card>
  <Card icon={<RulerHorizontalIcon />} title="Accurate distances">
    Measure the distance driven along roads instead of between noisy points.
  </Card>
  <Card icon={<ActivityLogIcon />} title="Movement analysis">
    Find which roads your vehicles actually use.
  </Card>
</Cards>

## Request

Send the trace as a JSON body on a `GET` request, with your key in the query string.

```bash
GET https://mapapi.gebeta.app/api/route/matching?apiKey={your-api-key}
Content-Type: application/json
```

| Field              | Type     | Required | Description                                                                               |
| ------------------ | -------- | -------- | ----------------------------------------------------------------------------------------- |
| `path`             | `array`  | Yes      | The GPS points in the order they were recorded. At least two different locations.         |
| `path[].lat`       | `number` | Yes      | Latitude.                                                                                 |
| `path[].lon`       | `number` | Yes      | Longitude. Note the name: `lon`, not `lng`.                                               |
| `path[].timestamp` | `string` | Yes      | When the point was recorded, in ISO 8601, such as `2026-05-28T10:30:00Z`.                 |
| `mode`             | `string` | No       | How the trace was travelled. Defaults to `auto` (driving); `pedestrian` is also accepted. |
| `shape_match`      | `string` | No       | How to match the points. Defaults to `map_snap`; `walk_or_snap` is also accepted.         |

<Callout title="Not callable from a browser">
  Browsers and the standard `fetch` API don't allow a body on a `GET` request, so call this endpoint
  from your server, a script or cURL.
</Callout>

```python
import requests

trace = {
    "path": [
        {"lat": 9.021175, "lon": 38.683022, "timestamp": "2026-05-28T10:30:00Z"},
        {"lat": 9.0209432, "lon": 38.6817064, "timestamp": "2026-05-28T10:30:05Z"},

    ],
    "mode": "auto",
    "shape_match": "map_snap",
}

response = requests.get(
    "https://mapapi.gebeta.app/api/route/matching",
    params={"apiKey": api_key},
    json=trace,
)
print(response.json()["distance"])
```

## Response

```json
{
  "path": [
    { "lat": 9.021378, "lon": 38.683007 },
    { "lat": 9.021341, "lon": 38.682509 },
    { "lat": 9.021336, "lon": 38.682277 }
  ],
  "distance": 1599.9125
}
```

| Field      | Description                                                                                                                                                                             |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `path`     | The matched route as `{ lat, lon }` points along the road. It usually has more points than you sent; the full response to the example above has 43. This example shows the first three. |
| `distance` | Length of the matched route, in meters.                                                                                                                                                 |

## Errors

| Status | `code`          | Cause                                                                                                                                                                                                                         |
| ------ | --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `401`  | `HE00004`       | The `apiKey` parameter is missing or the key is invalid.                                                                                                                                                                      |
| `400`  | `INVALID_INPUT` | The body is missing or invalid. `fields` says which part, for example `path must contain at least 2 distinct locations` or `invalid timestamp`.                                                                               |
| `503`  | `HE0000B`       | The trace couldn't be matched to roads. The real reason is in `error.additional.raw_body`, for example `map_snap algorithm failed to snap the shape points`. Check the points follow a road and the timestamps are realistic. |

```json
{
  "error": {
    "code": "INVALID_INPUT",
    "fields": { "input": ["path must contain at least 2 distinct locations"] },
    "message": "validation failed",
    "status": 400
  }
}
```
