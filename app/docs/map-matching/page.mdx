# Map Matching API

GPS points drift. A phone in a moving car can report positions in buildings, on the wrong side of the road or off the road entirely. The Map Matching API takes a trace of GPS points, works out which roads were most likely driven, and returns a clean path along them with its total distance.

## When to use it

<Cards>
  <Card icon={<MagicWandIcon />} title="Cleaning traces">
    Remove drift from tracking data before you show it or store it.
  </Card>
  <Card icon={<CounterClockwiseClockIcon />} title="Rebuilding trips">
    Reconstruct the route a delivery or service vehicle took from its GPS log.
  </Card>
  <Card icon={<RulerHorizontalIcon />} title="Accurate distances">
    Measure the distance driven along roads instead of between noisy points.
  </Card>
  <Card icon={<ActivityLogIcon />} title="Movement analysis">
    Find which roads your vehicles actually use.
  </Card>
</Cards>

## Request

```bash
GET https://mapapi.gebeta.app/api/route/matching/?path=[{lat,lng},{lat,lng}]&radius=1&apiKey={your-api-key}
```

| Parameter | Type     | Required | Description                                                         |
| --------- | -------- | -------- | ------------------------------------------------------------------- |
| `path`    | `string` | Yes      | The GPS points in the order they were recorded, as `[{lat,lng},…]`. |
| `radius`  | `number` | Yes      | How far from each point, in meters, to look for a road.             |
| `apiKey`  | `string` | Yes      | Your Gebeta Maps API key.                                           |

## Example

```bash
curl -g "https://mapapi.gebeta.app/api/route/matching/?path=[{9.019797,38.743688},{9.020316,38.74401},{9.020571,38.743619},{9.020883,38.743538},{9.020799,38.743876},{9.020952,38.744177}]&radius=1&apiKey={your-api-key}"
```

<Callout title="Use -g with curl">
  The brackets in `path` are curl's URL pattern syntax. `-g` turns that off so the URL is sent as
  written.
</Callout>

## Response

```json
{
  "coordinates": [
    [9.019822, 38.74364],
    [9.019915, 38.74369],
    [9.020158, 38.743841],
    [9.020444, 38.74401],
    [9.020767, 38.743394],
    [9.021026, 38.743539],
    [9.020723, 38.74414],
    [9.020915, 38.744249]
  ],
  "distance": 288.5191
}
```

| Field         | Description                                                                                              |
| ------------- | -------------------------------------------------------------------------------------------------------- |
| `coordinates` | The matched path as `[lat, lng]` points along the road. It can have more points than you sent, at turns. |
| `distance`    | Length of the matched path.                                                                              |

## Errors

| Status | Message                          | What to do                                                           |
| ------ | -------------------------------- | -------------------------------------------------------------------- |
| `401`  | `Not Authorized - No Token`      | Add your API key as the `apiKey` parameter.                          |
| `401`  | `Not Authorized - Invalid Token` | The key is wrong or expired. Copy a current key from your dashboard. |
| `404`  | `NoRoute`                        | No road matches the trace. Check the points or increase `radius`.    |
| `422`  | `InvalidInput`                   | Check that `path` is `[{lat,lng},…]` and `radius` is a number.       |

```json
{
  "error": {
    "code": "InvalidInput",
    "message": "Invalid path format. Please provide coordinates in the correct format.",
    "status": 422
  }
}
```
