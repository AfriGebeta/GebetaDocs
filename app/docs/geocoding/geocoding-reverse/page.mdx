# Reverse Geocoding

Reverse geocoding takes a latitude and longitude and returns what is there: the nearest address, street or place, with its city and country.

## Request

```bash
GET https://mapapi.gebeta.app/v2/search/reverse-geocoding?lat={latitude}&lon={longitude}&apiKey={your-api-key}
```

| Parameter | Type     | Required | Description                                                                                |
| --------- | -------- | -------- | ------------------------------------------------------------------------------------------ |
| `lat`     | `number` | Yes      | Latitude, from `-90` to `90`.                                                              |
| `lon`     | `number` | Yes      | Longitude, from `-180` to `180`.                                                           |
| `apiKey`  | `string` | Yes      | Your API key. You can send it as an `Authorization: Bearer {your-api-key}` header instead. |

### Optional parameters

| Parameter  | Type      | Description                                                   |
| ---------- | --------- | ------------------------------------------------------------- |
| `size`     | `integer` | How many results to return, from `1` to `5`. Defaults to `1`. |
| `category` | `string`  | Only return these categories, as a comma-separated list.      |

## Response

```json
{
  "data": {
    "query": "9.019200,38.757800",
    "results": [
      {
        "id": "way:123456",
        "name": "Bole Road",
        "display_name": "Bole Road, Addis Ababa, Ethiopia",
        "category": "highway",
        "location": { "lat": 9.019185, "lng": 38.757812 },
        "address": {
          "city": "Addis Ababa",
          "country": "Ethiopia",
          "country_code": "ETH"
        }
      }
    ]
  }
}
```

Results are sorted by distance from the point you sent. Every field is described in the [Geocoding overview](/geocoding#response), along with the [errors](/geocoding#errors) you can get back.
