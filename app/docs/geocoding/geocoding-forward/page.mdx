# Forward Geocoding

Forward geocoding looks up a place from text, such as an address, a street, a city or a business name, and returns its coordinates, a formatted address and where it sits in the country. It also handles partial text, so you can call it as someone types.

## Request

```bash
GET https://mapapi.gebeta.app/v2/search/geocode?query={search-text}&apiKey={your-api-key}
```

| Parameter | Type     | Required | Description                                                                                |
| --------- | -------- | -------- | ------------------------------------------------------------------------------------------ |
| `query`   | `string` | Yes      | What to look up: an address, street, city or place name. URL-encode it.                    |
| `apiKey`  | `string` | Yes      | Your API key. You can send it as an `Authorization: Bearer {your-api-key}` header instead. |

### Optional parameters

| Parameter      | Type      | Description                                                                                                   |
| -------------- | --------- | ------------------------------------------------------------------------------------------------------------- |
| `autocomplete` | `boolean` | Match partial words, for search-as-you-type. Defaults to `true`. Set `false` to match whole words only.       |
| `bbox`         | `string`  | Only return results inside this box, as `minLng,minLat,maxLng,maxLat`. For example `38.7,8.9,38.8,9.1`.       |
| `country`      | `string`  | Only return results in these countries, as comma-separated ISO codes. For example `et` or `et,ke`.            |
| `language`     | `string`  | The language for the text in the response.                                                                    |
| `limit`        | `integer` | How many results to return, from `1` to `10`.                                                                 |
| `proximity`    | `string`  | Prefer results near a point, as `lng,lat` (for example `38.75,9.02`), or `ip` to use the caller's IP address. |
| `category`     | `string`  | Only return these categories, as a comma-separated list.                                                      |

<Callout title="Coordinate order">
  `bbox` and `proximity` take longitude first (`lng,lat`). The response returns `lat` and `lng` as
  named fields.
</Callout>

## Examples

<Tabs items={["Basic", "Near a point", "One country", "Fewer results"]}>
<Tab value="Basic">

```bash
curl "https://mapapi.gebeta.app/v2/search/geocode?query=Bole+Road&apiKey={your-api-key}"
```

</Tab>
<Tab value="Near a point">

```bash
curl "https://mapapi.gebeta.app/v2/search/geocode?query=Hospital&proximity=38.75,9.02&apiKey={your-api-key}"
```

</Tab>
<Tab value="One country">

```bash
curl "https://mapapi.gebeta.app/v2/search/geocode?query=Bole&country=et&apiKey={your-api-key}"
```

</Tab>
<Tab value="Fewer results">

```bash
curl "https://mapapi.gebeta.app/v2/search/geocode?query=Bole&limit=2&apiKey={your-api-key}"
```

</Tab>
</Tabs>

## Response

```json
{
  "data": {
    "query": "Bole Road",
    "results": [
      {
        "id": "way:123456",
        "name": "Bole Road",
        "display_name": "Bole Road, Addis Ababa, Ethiopia",
        "category": "highway",
        "location": { "lat": 9.019185, "lng": 38.757812 },
        "address": {
          "city": "Addis Ababa",
          "country": "Ethiopia",
          "country_code": "ETH"
        }
      }
    ]
  }
}
```

Results are sorted by how well they match and how close they are. Every field is described in the [Geocoding overview](/geocoding#response), along with the [errors](/geocoding#errors) you can get back.
