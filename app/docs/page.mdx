# Introduction

Gebeta Maps gives you the building blocks for location features: find places, turn coordinates into addresses, plan routes for one vehicle or a whole fleet, and show it all on a map. Every API is a plain HTTPS request that returns JSON.

## Get an API key

Every request needs an API key. [Sign in to the dashboard](https://gebeta.app/#/auth/sign-in) to create one and manage your keys, then pass it as the `apiKey` query parameter.

```bash
curl "https://mapapi.gebeta.app/v2/search/geocode?query=Bole+Road&apiKey={your-api-key}"
```

<Callout title="Keep your key private">
  Anyone with your key can make requests on your account. Don't commit it to a public repository or
  ship it in client code you don't control.
</Callout>
