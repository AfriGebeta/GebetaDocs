# Embed Map

You can put an interactive Gebeta map on any website with a single `<iframe>`. You set it up in the dashboard, with a center, markers and an optional boundary, and get a snippet to paste. There's no SDK to install, and no API key in the page.

## Before you start

You need two tokens from a service account in your dashboard, under **Service Accounts**:

- **Server token:** created with Admin on.
- **Client token:** created with Admin off.

## Set up the map

### 1. Open Map Embed

In the dashboard sidebar, go to **Map Embed**. The page has two token fields and a map.

### 2. Load the map

Paste your server and client tokens, then click **Load Map to Configure**. The map opens on Addis Ababa at zoom 13, with a blue dot marking the center.

### 3. Set the center

**Set Center** mode is on by default. Click the map, or drag the blue dot, to move the center. This is where the embed opens. The coordinates update below the map as you move it.

### 4. Add markers (optional)

Switch to **Drop Marker** in the toolbar and click the map to place orange markers, as many as you need. Each one appears in a list below the map, where you can give it a label. The label shows in a popup when someone clicks the marker. Click the trash icon to remove one.

### 5. Limit the area (optional)

To keep people within one city, campus or venue, click **Draw Bounds** and then click two opposite corners on the map. A dashed box shows the area. People can't pan outside it, and the minimum zoom is set so they can't zoom out past it. **Clear Bounds** removes it.

### 6. Generate the embed

Click **Generate Embed**. The page shows a live preview and the snippet to copy:

```html
<iframe
  src="https://maps.gebeta.app/embed/map?t=eyJ..."
  width="600"
  height="450"
  style="border:0;border-radius:8px"
  allowfullscreen
  loading="lazy"
></iframe>
```

<Callout title="Safe to publish">
  The `t` parameter is an encrypted copy of your map settings. It doesn't contain your server or
  client token, so the snippet is safe to put on a public page.
</Callout>

## Add it to your site

Paste the snippet into any page, CMS or site builder that accepts HTML. Set `width="100%"` to fill the space it's in:

```html
<!DOCTYPE html>
<html>
  <body>
    <h1>Find us</h1>
    <iframe
      src="https://maps.gebeta.app/embed/map?t=eyJ..."
      width="100%"
      height="450"
      style="border:0;border-radius:8px"
      allowfullscreen
      loading="lazy"
    ></iframe>
  </body>
</html>
```

## What the embed includes

| Feature         | Details                                                  |
| --------------- | -------------------------------------------------------- |
| Center and zoom | Where you set them in the dashboard.                     |
| Markers         | As many as you added, each with an optional label popup. |
| Bounds          | A hard limit on panning and zooming out.                 |
| Zoom buttons    | Built in.                                                |
| View larger map | Opens the full Gebeta Maps app at the same place.        |
| Security        | No tokens or keys in the iframe URL.                     |

## Change an embed

An embed is a snapshot of the settings when you generated it. To change the center, markers or bounds, set the map up again in **Map Embed** and generate a new snippet to replace the old one.
