# Tracking API

The Tracking API streams live locations over one WebSocket connection. Drivers send their position every few seconds, and offices subscribe to one driver or the whole fleet and get each update as it arrives. Use it for fleet maps, delivery tracking and dispatch screens.

## How it works

1. A client connects to `wss://track.gebeta.app/v1/track` and authenticates as a `driver` or an `office`.
2. Drivers send `driver_location` messages while they're moving.
3. Offices send `subscribe` for the drivers they want, then receive a `location_update` for every position those drivers send.

| Role     | What it does                      |
| -------- | --------------------------------- |
| `driver` | Sends its own location updates.   |
| `office` | Subscribes to drivers' locations. |

Offices only ever receive locations from drivers in their own company.

## Connect and authenticate

```bash
wss://track.gebeta.app/v1/track
```

Send this as the first message after the connection opens:

```json
{
  "action": "authenticate",
  "payload": {
    "user_id": "DR_1",
    "role": "driver",
    "token": "<JWT_TOKEN>"
  }
}
```

| Field     | Type     | Required | Description                            |
| --------- | -------- | -------- | -------------------------------------- |
| `user_id` | `string` | Yes      | A unique ID for this driver or office. |
| `role`    | `string` | Yes      | `driver` or `office`.                  |
| `token`   | `string` | Yes      | A valid JWT access token.              |

The connection closes when the token expires, so reconnect with a fresh token.

## Send locations (drivers)

```json
{
  "action": "driver_location",
  "id": "DR_1",
  "payload": {
    "lat": 9.01234,
    "lng": 38.70321,
    "speed": 14.5,
    "bearing": 90
  }
}
```

| Field     | Type     | Description                          |
| --------- | -------- | ------------------------------------ |
| `lat`     | `number` | Latitude.                            |
| `lng`     | `number` | Longitude.                           |
| `speed`   | `number` | Speed in km/h.                       |
| `bearing` | `number` | Heading in degrees, `0` being north. |

<Callout title="Update every 2–5 seconds">
  That keeps markers moving smoothly without wasting battery or data. The server accepts at most one
  update per second per driver.
</Callout>

## Subscribe (offices)

To follow one driver:

```json
{ "action": "subscribe", "entity": "driver:DR_1" }
```

To follow every driver in your company:

```json
{ "action": "subscribe", "entity": "company:drivers" }
```

Each location a subscribed driver sends then arrives as:

```json
{
  "type": "location_update",
  "id": "DR_1",
  "payload": {
    "lat": 9.01345,
    "lng": 38.70412,
    "speed": 13.2,
    "bearing": 90
  }
}
```

## Keep the connection alive

The server sends WebSocket ping frames to check the connection. Answer each with a pong. Browsers do this for you; in Node.js with `ws`:

```javascript
ws.on("ping", () => ws.pong());
```

## Examples

<Tabs items={["Driver (Node.js)", "Office (Node.js)"]}>
<Tab value="Driver (Node.js)">

```javascript
import WebSocket from "ws";

const ws = new WebSocket("wss://track.gebeta.app/v1/track");

ws.on("open", () => {
  ws.send(
    JSON.stringify({
      action: "authenticate",
      payload: { user_id: "DR_1", role: "driver", token: "<JWT_TOKEN>" },
    })
  );

  setInterval(() => {
    ws.send(
      JSON.stringify({
        action: "driver_location",
        id: "DR_1",
        payload: { lat: 9.01234, lng: 38.70321, speed: 12, bearing: 90 },
      })
    );
  }, 3000);
});

ws.on("ping", () => ws.pong());
```

<Tab value="Office (Node.js)">

```javascript
import WebSocket from "ws";

const ws = new WebSocket("wss://track.gebeta.app/v1/track");

ws.on("open", () => {
  ws.send(
    JSON.stringify({
      action: "authenticate",
      payload: { user_id: "office_1", role: "office", token: "<JWT_TOKEN>" },
    })
  );

  ws.send(JSON.stringify({ action: "subscribe", entity: "driver:DR_1" }));
});

ws.on("message", (message) => {
  const update = JSON.parse(message);
  if (update.type === "location_update") {
    console.log(update.id, update.payload.lat, update.payload.lng);
  }
});

ws.on("ping", () => ws.pong());
```

## Errors

| Error           | Cause                                                                   |
| --------------- | ----------------------------------------------------------------------- |
| `Unauthorized`  | The token is missing, invalid or expired.                               |
| `InvalidAction` | `action` isn't one of `authenticate`, `driver_location` or `subscribe`. |
| `Forbidden`     | The subscription is for a driver outside your company.                  |
| `BadPayload`    | A required field is missing or has the wrong type.                      |

## Limits

- **Update rate:** At most one location per second per driver.
- **Connections:** The maximum number of open connections is set per company.
- **Tokens:** Connections close when their token expires.
