# Route Optimization API

Give the Route Optimization API a list of stops and it returns the order that visits them all in the least time, as a round trip that starts and ends at the first stop. You also get the total time and distance and the full route to draw on a map. This is the travelling salesman problem, solved over real roads.

## When to use it

<Cards>
  <Card icon={<CubeIcon />} title="Single-driver deliveries">
    Order a courier's drops so they drive as little as possible.
  </Card>
  <Card icon={<LoopIcon />} title="Service rounds">
    Plan a technician's or sales rep's visits for the day.
  </Card>
  <Card icon={<SewingPinFilledIcon />} title="Trips">
    Find the best order to see several places and get back to the start.
  </Card>
</Cards>

To split stops across several vehicles with capacities, use the [VRP API](/vrp). To keep the stops in your own order, use the [Direction API](/direction) with `waypoints`.

## Request

```bash
GET https://mapapi.gebeta.app/api/route/tss?json=[{lat,lng},{lat,lng}]&apiKey={your-api-key}
```

| Parameter | Type     | Required | Description                                                                                          |
| --------- | -------- | -------- | ---------------------------------------------------------------------------------------------------- |
| `json`    | `string` | Yes      | The stops, as `[{lat,lng},{lat,lng},…]`. The first stop is where the trip starts and ends. Up to 10. |
| `apiKey`  | `string` | Yes      | Your Gebeta Maps API key.                                                                            |

## Response

```json
{
  "msg": "Ok",
  "best_order": [
    { "lat": 9.056218, "lon": 38.705173 },
    { "lat": 9.030789, "lon": 38.730922, "index": 1, "original_index": 1 },
    { "lat": 9.047741, "lon": 38.756671, "index": 2, "original_index": 2 },
    { "lat": 9.056218, "lon": 38.705173, "index": 3, "original_index": 3 }
  ],
  "original_order": [
    { "lat": 9.056218147277832, "lon": 38.70517349243164 },
    { "lat": 9.030789375305176, "lon": 38.73092269897461, "index": 1 },
    { "lat": 9.047741889953613, "lon": 38.75667190551758, "index": 2 },
    { "lat": 9.056218147277832, "lon": 38.70517349243164, "index": 3 }
  ],
  "total_distance": 19.698,
  "time_taken": 2774.798,
  "Direction": [[9.055978, 38.704943]]
}
```

| Field            | Description                                                                                                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `msg`            | `Ok` when a trip was found.                                                                                                                                              |
| `best_order`     | The stops in the order to visit them, snapped to the nearest road. It starts and ends at your first stop. `original_index` is each stop's position in the list you sent. |
| `original_order` | The stops in the order you sent them, ending back at the first one.                                                                                                      |
| `total_distance` | Length of the whole round trip, in kilometers.                                                                                                                           |
| `time_taken`     | Travel time for the whole round trip, in seconds.                                                                                                                        |
| `Direction`      | The route as `[lat, lng]` points, in driving order. Note the capital `D`. A real response has hundreds of points; this example shows only the first.                     |

## Errors

| Status | Message                          | What to do                                                           |
| ------ | -------------------------------- | -------------------------------------------------------------------- |
| `401`  | `Not Authorized - No Token`      | Add your API key as the `apiKey` parameter.                          |
| `401`  | `Not Authorized - Invalid Token` | The key is wrong or expired. Copy a current key from your dashboard. |
| `404`  | `NoRoute`                        | At least one stop can't be reached by road from the others.          |
| `422`  | `InvalidInput`                   | Check that `json` is `[{lat,lng},…]`.                                |

```json
{
  "error": {
    "additional": null,
    "code": "A_ERR00004",
    "message": "Invalid access token!",
    "status": 401
  }
}
```

## Limits

- **Stops:** Up to 10 per request, including the start.
- **Rate:** 50 requests per second per API key. Requests above that are rejected, so throttle or batch them.
- **Countries:** All stops must be in the same country.
