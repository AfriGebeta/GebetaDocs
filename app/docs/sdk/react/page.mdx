# React

`@gebeta/react` wraps [`@gebeta/js`](/sdk/js) in a `GebetaMap` component. It creates the map when it mounts, removes it when it unmounts, and loads the MapLibre stylesheet for you. It needs React 19.

```bash
npm install @gebeta/react
```

## Show a map

```jsx
import { GebetaMap } from "@gebeta/react";

export function StoreMap({ auth }) {
  return <GebetaMap auth={auth} center={[38.7578, 9.0192]} zoom={13} style={{ height: 400 }} />;
}
```

`auth` is the `{ accessToken, refreshToken }` pair from your backend; see [Authentication](/sdk/authentication). Pass `apiKey` instead while prototyping.

The map fills its parent by default, so give either the component or its parent a height.

## Props

| Prop                        | Type                            | Description                                                                               |
| --------------------------- | ------------------------------- | ----------------------------------------------------------------------------------------- |
| `auth`                      | `{ accessToken, refreshToken }` | Tokens from your backend. Changing the tokens recreates the map.                          |
| `apiKey`                    | `string`                        | Your API key, instead of `auth`. Passing both throws a `ValidationError`.                 |
| `center`                    | `[lng, lat]`                    | Where the map starts. Only read on mount; move the map with `flyTo()` afterwards.         |
| `zoom`                      | `number`                        | The starting zoom. Only read on mount.                                                    |
| `mapStyle`                  | `string \| object`              | A style URL or style object. See [Map styles](/sdk/js#map-styles).                        |
| `styleUrl`                  | `string`                        | A style URL. `mapStyle` wins if you pass both.                                            |
| `clustering`                | `object`                        | Turns on [clustering](/sdk/markers), for example `{ enabled: true }`. Only read on mount. |
| `navigationControl`         | `boolean`                       | Shows zoom and compass buttons.                                                           |
| `navigationControlPosition` | `string`                        | Corner for the buttons. Defaults to `top-right`.                                          |
| `onLoad`                    | `(gebeta) => void`              | Called once the map has loaded, with the `GebetaMaps` instance.                           |
| `onError`                   | `(error) => void`               | Called when the map reports an error, such as a style or tile that won't load.            |
| `style`, `className`        |                                 | Style the wrapper element, not the map.                                                   |
| `children`                  | `ReactNode`                     | Drawn over the map once it has loaded.                                                    |

Other [MapLibre map options](https://maplibre.org/maplibre-gl-js/docs/API/type-aliases/MapOptions/), such as `pitch`, `bearing` or `maxBounds`, are passed through.

## Use the map instance

`onLoad` gives you the same `GebetaMaps` instance as the [JavaScript SDK](/sdk/js), with every manager ready. Keep it in state to use it from event handlers:

```jsx
import { useState } from "react";
import { GebetaMap } from "@gebeta/react";

export function DeliveryRoute({ auth }) {
  const [gebeta, setGebeta] = useState(null);
  const [summary, setSummary] = useState("");

  async function showRoute() {
    const route = await gebeta.getDirections(
      { lat: 8.989022, lng: 38.79036 },
      { lat: 9.03045, lng: 38.7653 }
    );
    gebeta.displayRoute(route);
    setSummary(`${route.distance} · ${route.duration}`);
  }

  return (
    <>
      <button onClick={showRoute} disabled={!gebeta}>
        Show route
      </button>
      <p>{summary}</p>
      <GebetaMap
        auth={auth}
        center={[38.7785, 9.0098]}
        zoom={12}
        style={{ height: 400 }}
        onLoad={setGebeta}
      />
    </>
  );
}
```

You can also pass a `ref`. `ref.current` is the instance once `onLoad` has fired, and `null` after the map unmounts. For the MapLibre map, call `gebeta.getMap()`.

## Clustered markers

Turn on clustering with the `clustering` prop, then call `useClustering()` from a component rendered inside `GebetaMap`:

```jsx
import { useEffect } from "react";
import { GebetaMap, useClustering } from "@gebeta/react";

function Stores({ stores }) {
  const { addMarker, clearMarkers } = useClustering();

  useEffect(() => {
    stores.forEach((store) => addMarker({ id: store.id, lngLat: store.lngLat }));
    return () => clearMarkers();
  }, [stores]);

  return null;
}

export function StoresMap({ auth, stores }) {
  return (
    <GebetaMap auth={auth} clustering={{ enabled: true }} style={{ height: 500 }}>
      <Stores stores={stores} />
    </GebetaMap>
  );
}
```

`useClustering()` returns `addMarker`, `removeMarker`, `clearMarkers`, `getMarkers`, `getMarker`, `updateOptions` and `getOptions`. It throws if the parent map doesn't have clustering on. The marker fields are in [Markers](/sdk/markers#marker-options).

## Next.js

The map only runs in the browser. Put it in its own component and load that with `ssr: false`, so Next.js doesn't try to render it on the server:

```jsx title="components/store-map.jsx"
"use client";

import { GebetaMap } from "@gebeta/react";

export default function StoreMap({ auth }) {
  return <GebetaMap auth={auth} center={[38.7578, 9.0192]} zoom={13} style={{ height: 400 }} />;
}
```

```jsx title="components/store-map-loader.jsx"
"use client";

import dynamic from "next/dynamic";

export const StoreMap = dynamic(() => import("./store-map"), { ssr: false });
```
