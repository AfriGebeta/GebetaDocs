# React

`@gebeta/react` wraps [`@gebeta/js`](/sdk/js) in a `GebetaMap` component. It creates the map when it mounts and removes it when it unmounts. It needs React 19.

```bash
npm install @gebeta/react
```

Import the stylesheet once, for example next to your map component. Without it, markers, popups and controls aren't positioned on the map:

```jsx
import "@gebeta/js/style.css";
```

## Show a map

```jsx
import { GebetaMap } from "@gebeta/react";
import "@gebeta/js/style.css";

export function StoreMap({ auth }) {
  return <GebetaMap auth={auth} center={[38.7578, 9.0192]} zoom={13} style={{ height: 400 }} />;
}
```

`auth` is the `{ accessToken, refreshToken }` pair from your backend; see [Authentication](/sdk/authentication). Pass `apiKey` instead while prototyping.

The map fills its parent by default, so give either the component or its parent a height.

## Props

| Prop                        | Type                            | Description                                                                                                           |
| --------------------------- | ------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `auth`                      | `{ accessToken, refreshToken }` | Tokens from your backend. Changing the tokens recreates the map.                                                      |
| `apiKey`                    | `string`                        | Your API key, instead of `auth`. Passing both throws a `ValidationError`.                                             |
| `center`                    | `[lng, lat]`                    | Where the map starts. Only read on mount; move the map with `flyTo()` afterwards.                                     |
| `zoom`                      | `number`                        | The starting zoom. Only read on mount.                                                                                |
| `mapStyle`                  | `string \| object`              | A style URL or style object. See [Map styles](/sdk/js#map-styles).                                                    |
| `styleUrl`                  | `string`                        | A style URL. `mapStyle` wins if you pass both.                                                                        |
| `clustering`                | `object`                        | Turns on [clustering](/sdk/markers), for example `{ enabled: true }`. Only read on mount.                             |
| `navigationControl`         | `boolean`                       | Shows zoom and compass buttons.                                                                                       |
| `navigationControlPosition` | `string`                        | Corner for the buttons. Defaults to `top-right`.                                                                      |
| `ref`                       | `RefObject<GebetaMaps>`         | Receives the `GebetaMaps` instance once loaded; `null` after unmount. Prefer this over `onLoad` for imperative calls. |
| `onLoad`                    | `(gebeta) => void`              | Called once the map has loaded, with the `GebetaMaps` instance.                                                       |
| `onError`                   | `(error) => void`               | Called when the map reports an error, such as a style or tile that won't load.                                        |
| `style`, `className`        |                                 | Style the wrapper element, not the map.                                                                               |
| `children`                  | `ReactNode`                     | Drawn over the map once it has loaded.                                                                                |

Other [MapLibre map options](https://maplibre.org/maplibre-gl-js/docs/API/type-aliases/MapOptions/), such as `pitch`, `bearing` or `maxBounds`, are passed through.

## Use the map instance

Pass a `ref` to get the `GebetaMaps` instance. `gebetaRef.current` is set once `onLoad` fires and cleared when the map unmounts. Storing it in a ref — not state — means the map load never triggers a re-render:

```jsx
import { useRef } from "react";
import { GebetaMap } from "@gebeta/react";
import "@gebeta/js/style.css";

export function MapWithInstance({ auth }) {
  const gebetaRef = useRef(null);

  return (
    <GebetaMap
      ref={gebetaRef}
      auth={auth}
      center={[38.7785, 9.0098]}
      zoom={12}
      style={{ height: 400 }}
    />
  );
}
```

For the underlying MapLibre map, call `gebetaRef.current.getMap()`.

## Geocoding

```jsx
import { useRef, useState } from "react";
import { GebetaMap } from "@gebeta/react";
import "@gebeta/js/style.css";

export function PlaceSearch({ auth }) {
  const gebetaRef = useRef(null);
  const [results, setResults] = useState([]);

  async function search(query) {
    if (!gebetaRef.current) return;
    const places = await gebetaRef.current.geocodingManager.geocode(query);
    setResults(places);
  }

  return (
    <>
      <input placeholder="Search places..." onChange={(e) => search(e.target.value)} />
      <ul>
        {results.map((place, i) => (
          <li key={i}>{place.name}</li>
        ))}
      </ul>
      <GebetaMap
        ref={gebetaRef}
        auth={auth}
        center={[38.7578, 9.0192]}
        zoom={13}
        style={{ height: 400 }}
      />
    </>
  );
}
```

For reverse geocoding, call `gebetaRef.current.geocodingManager.reverseGeocode({ lat, lng })`. See [Geocoding](/sdk/geocoding) for all options.

## Directions

```jsx
import { useRef, useState } from "react";
import { GebetaMap } from "@gebeta/react";
import "@gebeta/js/style.css";

export function DeliveryRoute({ auth }) {
  const gebetaRef = useRef(null);
  const [summary, setSummary] = useState("");

  async function showRoute() {
    if (!gebetaRef.current) return;
    const route = await gebetaRef.current.getDirections(
      { lat: 8.989022, lng: 38.79036 },
      { lat: 9.03045, lng: 38.7653 }
    );
    gebetaRef.current.displayRoute(route);
    setSummary(`${route.distance} · ${route.duration}`);
  }

  return (
    <>
      <button onClick={showRoute}>Show route</button>
      <p>{summary}</p>
      <GebetaMap
        ref={gebetaRef}
        auth={auth}
        center={[38.7785, 9.0098]}
        zoom={12}
        style={{ height: 400 }}
      />
    </>
  );
}
```

`getDirections` and `displayRoute` are on the `GebetaMaps` instance. See [Directions](/sdk/directions) for stops, waypoints, and turn-by-turn instructions.

## Markers and clustering

Use `onLoad` to add markers directly — this is one place where `onLoad` is still the right choice since you're firing a one-time setup, not storing the instance:

```jsx
import { GebetaMap } from "@gebeta/react";
import "@gebeta/js/style.css";

export function StoreMap({ auth }) {
  function handleLoad(gebeta) {
    gebeta.addMarker({
      lngLat: [38.7613, 9.0106],
      anchor: "bottom",
      popup: "Meskel Square",
    });
  }

  return (
    <GebetaMap
      auth={auth}
      center={[38.7613, 9.0106]}
      zoom={14}
      style={{ height: 400 }}
      onLoad={handleLoad}
    />
  );
}
```

Turn on clustering with the `clustering` prop, then call `useClustering()` from a component rendered inside `GebetaMap`:

```jsx
import { useEffect } from "react";
import { GebetaMap, useClustering } from "@gebeta/react";
import "@gebeta/js/style.css";

function Stores({ stores }) {
  const { addMarker, clearMarkers } = useClustering();

  useEffect(() => {
    stores.forEach((store) => addMarker({ id: store.id, lngLat: store.lngLat }));
    return () => clearMarkers();
  }, [stores]);

  return null;
}

export function StoresMap({ auth, stores }) {
  return (
    <GebetaMap auth={auth} clustering={{ enabled: true }} style={{ height: 500 }}>
      <Stores stores={stores} />
    </GebetaMap>
  );
}
```

`useClustering()` returns `addMarker`, `removeMarker`, `clearMarkers`, `getMarkers`, `getMarker`, `updateOptions` and `getOptions`. It throws if the parent map doesn't have clustering on. The marker fields are in [Markers](/sdk/markers#marker-options).

## Geofencing

```jsx
import { useRef } from "react";
import { GebetaMap } from "@gebeta/react";
import "@gebeta/js/style.css";

export function FenceMap({ auth }) {
  const gebetaRef = useRef(null);

  function showZone() {
    if (!gebetaRef.current) return;
    gebetaRef.current.fencing.renderFences([
      {
        id: "delivery-zone",
        name: "Delivery zone",
        points: [
          [38.74, 8.99],
          [38.79, 8.99],
          [38.79, 9.04],
          [38.74, 9.04],
        ],
        color: "#2563eb",
      },
    ]);
  }

  return (
    <>
      <button onClick={showZone}>Show delivery zone</button>
      <GebetaMap
        ref={gebetaRef}
        auth={auth}
        center={[38.765, 9.015]}
        zoom={12}
        style={{ height: 400 }}
      />
    </>
  );
}
```

To let users draw a fence by clicking the map, call `gebetaRef.current.fencing.startDrawing()`. See [Geofencing](/sdk/fencing).

## Navigation

```jsx
import { useRef } from "react";
import { GebetaMap, BrowserLocationProvider } from "@gebeta/react";
import "@gebeta/js/style.css";

export function NavigationMap({ auth }) {
  const gebetaRef = useRef(null);

  async function startNav() {
    if (!gebetaRef.current) return;
    const route = await gebetaRef.current.getDirections(
      { lat: 8.989022, lng: 38.79036 },
      { lat: 9.03045, lng: 38.7653 }
    );
    gebetaRef.current.displayRoute(route);
    gebetaRef.current.navigation.start(
      route,
      { userId: "driver-1" },
      new BrowserLocationProvider()
    );
    gebetaRef.current.navigation.on("arrived", () => alert("Arrived!"));
  }

  return (
    <>
      <button onClick={startNav}>Start navigation</button>
      <GebetaMap
        ref={gebetaRef}
        auth={auth}
        center={[38.7785, 9.0098]}
        zoom={14}
        style={{ height: 400 }}
      />
    </>
  );
}
```

See [Navigation](/sdk/navigation) for the full event list and off-route handling.

## Controls and geo helpers

`@gebeta/react` re-exports the map building blocks (controls, `Marker`, `Popup`, `LngLatBounds` and more), so you never import from the rendering engine:

```jsx
import { ScaleControl, FullscreenControl, LngLatBounds } from "@gebeta/react";

function handleLoad(gebeta) {
  const map = gebeta.getMap();
  map.addControl(new ScaleControl(), "bottom-left");
  map.addControl(new FullscreenControl(), "top-left");

  const bounds = new LngLatBounds();
  coordinates.forEach((c) => bounds.extend(c));
  map.fitBounds(bounds, { padding: 64 });
}
```

## Next.js

The map only runs in the browser. Put it in its own component and load that with `ssr: false`, so Next.js doesn't try to render it on the server:

```jsx title="components/store-map.jsx"
"use client";

import { GebetaMap } from "@gebeta/react";
import "@gebeta/js/style.css";

export default function StoreMap({ auth }) {
  return <GebetaMap auth={auth} center={[38.7578, 9.0192]} zoom={13} style={{ height: 400 }} />;
}
```

```jsx title="components/store-map-loader.jsx"
"use client";

import dynamic from "next/dynamic";

export const StoreMap = dynamic(() => import("./store-map"), { ssr: false });
```
