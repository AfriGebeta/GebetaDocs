# Matrix API

The Matrix API takes a list of coordinates and returns the travel duration and distance between every pair of them. Send ten points and you get all 100 trips back, so you can rank, sort or plan without making a directions call for each pair.

## When to use it

## Request

```bash
GET https://mapapi.gebeta.app/api/route/matrix?json=[{lat,lng},{lat,lng}]&apiKey={your-api-key}
```

| Parameter | Type     | Required | Description                                                                                                 |
| --------- | -------- | -------- | ----------------------------------------------------------------------------------------------------------- |
| `json`    | `string` | Yes      | The points, as `[{lat,lng},{lat,lng},…]`. Every point is both an origin and a destination. Up to 10 points. |
| `apiKey`  | `string` | Yes      | Your Gebeta Maps API key.                                                                                   |

## Response

`origin_to_destination` has one entry for every pair of points, including each point to itself. `from` and `to` are positions in the list you sent.

```json
{
  "origins": [
    { "lat": 9.055978, "lon": 38.704943, "radius": null },
    { "lat": 9.030787, "lon": 38.730911, "radius": null },
    { "lat": 9.047874, "lon": 38.756519, "radius": null }
  ],
  "destinations": [
    { "lat": 9.055978, "lon": 38.704943, "radius": null },
    { "lat": 9.030787, "lon": 38.730911, "radius": null },
    { "lat": 9.047874, "lon": 38.756519, "radius": null }
  ],
  "origin_to_destination": [
    { "from": 0, "to": 0, "distance": 0, "time": 0 },
    { "from": 0, "to": 1, "distance": 6.067, "time": 878 },
    { "from": 0, "to": 2, "distance": 9.547, "time": 1264 },
    { "from": 1, "to": 0, "distance": 6.795, "time": 971 },
    { "from": 1, "to": 1, "distance": 0, "time": 0 },
    { "from": 1, "to": 2, "distance": 4.393, "time": 641 },
    { "from": 2, "to": 0, "distance": 8.699, "time": 1144 },
    { "from": 2, "to": 1, "distance": 4.307, "time": 614 },
    { "from": 2, "to": 2, "distance": 0, "time": 0 }
  ]
}
```

| Field                              | Description                                                                  |
| ---------------------------------- | ---------------------------------------------------------------------------- |
| `origins`                          | The points used as origins, snapped to the nearest road, as `lat` and `lon`. |
| `destinations`                     | The points used as destinations, snapped the same way.                       |
| `origin_to_destination[].from`     | Position of the starting point in the list you sent.                         |
| `origin_to_destination[].to`       | Position of the end point in the list you sent.                              |
| `origin_to_destination[].distance` | Road distance in kilometers.                                                 |
| `origin_to_destination[].time`     | Travel time in seconds.                                                      |

A trip and its return can differ, because of one-way streets and turns. In the example, point 0 to point 1 is 6.1 km but the way back is 6.8 km.

<Callout title="Points are snapped to roads">
  The coordinates in `origins` and `destinations` can differ slightly from the ones you sent. The
  API moves each point to the nearest routable road before measuring.
</Callout>

## Errors

| Status | Message                          | What to do                                                           |
| ------ | -------------------------------- | -------------------------------------------------------------------- |
| `401`  | `Not Authorized - No Token`      | Add your API key as the `apiKey` parameter.                          |
| `401`  | `Not Authorized - Invalid Token` | The key is wrong or expired. Copy a current key from your dashboard. |
| `404`  | `NoRoute`                        | At least one pair of points has no road between them.                |
| `422`  | `InvalidInput`                   | Check the `json` format and that every point is a valid lat/lng.     |

Errors come back in this shape:

```json
{
  "error": {
    "additional": null,
    "code": "A_ERR00004",
    "message": "Invalid access token!",
    "status": 401
  }
}
```

## Limits

- **Points:** Up to 10 per request.
- **Rate:** 50 requests per second per API key. Requests above that are rejected, so throttle or batch them.
- **Countries:** All points must be in the same country. Requests that cross a border are rejected.
