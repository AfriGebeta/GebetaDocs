# VRP API

The VRP (vehicle routing problem) API plans deliveries for a whole fleet. Send your vehicles with how much each can carry, your customers with how much each ordered, and the depots the orders come from. It returns which customers each driver should serve, from which depot, in what order.

## When to use it

<Cards>
  <Card icon={<ArchiveIcon />} title="Delivery fleets">
    Assign the day's orders to drivers without overloading any vehicle.
  </Card>
  <Card icon={<HomeIcon />} title="Several warehouses">
    Make sure each order is picked up from the depot it was placed with.
  </Card>
  <Card icon={<PaperPlaneIcon />} title="Dispatch">
    Re-plan when new orders come in, starting from where each driver is now.
  </Card>
</Cards>

For a single vehicle with no capacity limit, the [Route Optimization API](/route-optimization) is simpler.

## Request

```bash
POST https://mapapi.gebeta.app/api/optimized-trip?apiKey={your-api-key}
Content-Type: application/json
```

The body has three lists, all required.

### `vehicles`

| Field              | Type      | Description                                              |
| ------------------ | --------- | -------------------------------------------------------- |
| `name`             | `string`  | The driver or vehicle name. Returned in the result.      |
| `current_location` | `array`   | Where the vehicle is now, as `[lat, lng]`.               |
| `capacities`       | `integer` | How many boxes the vehicle can carry, as a whole number. |

### `customers`

| Field                  | Type     | Description                                          |
| ---------------------- | -------- | ---------------------------------------------------- |
| `name`                 | `string` | The customer or order name. Returned in the result.  |
| `location`             | `array`  | Where to deliver, as `[lat, lng]`.                   |
| `demand`               | `number` | How many boxes this customer ordered.                |
| `requested_from_depot` | `string` | The `name` of the depot this order has to come from. |

### `depots`

| Field      | Type     | Description                                                      |
| ---------- | -------- | ---------------------------------------------------------------- |
| `name`     | `string` | The depot name. Customers refer to it in `requested_from_depot`. |
| `location` | `array`  | Where the depot is, as `[lat, lng]`.                             |

## Example

```bash
curl -X POST "https://mapapi.gebeta.app/api/optimized-trip?apiKey={your-api-key}" \
  -H "Content-Type: application/json" \
  -d '{
    "vehicles": [
      { "name": "driver 1", "current_location": [9.020929, 38.801699], "capacities": 3 },
      { "name": "driver 2", "current_location": [9.020929, 38.801699], "capacities": 3 }
    ],
    "customers": [
      { "name": "a", "location": [9.022359, 38.799478], "demand": 1, "requested_from_depot": "bole-warehouse" },
      { "name": "b", "location": [9.020431, 38.800401], "demand": 1, "requested_from_depot": "bole-warehouse" },
      { "name": "c", "location": [9.021167, 38.798894], "demand": 1, "requested_from_depot": "bole-warehouse" },
      { "name": "d", "location": [9.023101, 38.804816], "demand": 1, "requested_from_depot": "bole-warehouse" },
      { "name": "e", "location": [9.022455, 38.804864], "demand": 1, "requested_from_depot": "bole-warehouse" },
      { "name": "f", "location": [9.020251, 38.804151], "demand": 1, "requested_from_depot": "bole-warehouse" }
    ],
    "depots": [
      { "name": "bole-warehouse", "location": [9.020929, 38.801699] }
    ]
  }'
```

## Response

`routes` has one entry per driver that was given work. Each lists the depot to load at and the customers to visit, in order.

```json
{
  "routes": [
    {
      "driver": "driver 1",
      "depot": { "name": "bole-warehouse", "location": [9.020929, 38.801699] },
      "customers": [
        { "name": "b", "location": [9.020431, 38.800401], "requestedFromDepot": "bole-warehouse" },
        { "name": "c", "location": [9.021167, 38.798894], "requestedFromDepot": "bole-warehouse" },
        { "name": "a", "location": [9.022359, 38.799478], "requestedFromDepot": "bole-warehouse" }
      ]
    },
    {
      "driver": "driver 2",
      "depot": { "name": "bole-warehouse", "location": [9.020929, 38.801699] },
      "customers": [
        { "name": "f", "location": [9.020251, 38.804151], "requestedFromDepot": "bole-warehouse" },
        { "name": "e", "location": [9.022455, 38.804864], "requestedFromDepot": "bole-warehouse" },
        { "name": "d", "location": [9.023101, 38.804816], "requestedFromDepot": "bole-warehouse" }
      ]
    }
  ]
}
```

| Field                                     | Description                                     |
| ----------------------------------------- | ----------------------------------------------- |
| `routes[].driver`                         | The vehicle `name` this route is for.           |
| `routes[].depot`                          | The depot the driver loads at.                  |
| `routes[].customers`                      | The customers to deliver to, in visiting order. |
| `routes[].customers[].requestedFromDepot` | The depot the order came from.                  |

To draw a route, start at `depot.location` and connect each customer's `location` in order. For the road path between them, pass those points to the [Direction API](/direction) as `waypoints`.

## Errors

| Status | Message                          | What to do                                                                 |
| ------ | -------------------------------- | -------------------------------------------------------------------------- |
| `401`  | `Not Authorized - No Token`      | Add your API key as the `apiKey` parameter.                                |
| `401`  | `Not Authorized - Invalid Token` | The key is wrong or expired. Copy a current key from your dashboard.       |
| `404`  | `NoRoute`                        | A customer or depot can't be reached by road.                              |
| `422`  | `InvalidInput`                   | Check the body: all three lists, and every location as a two-number array. |

## Limits

- **Rate:** 50 requests per second per API key. Requests above that are rejected, so throttle or batch them.
- **Countries:** All vehicles, customers and depots must be in the same country.
