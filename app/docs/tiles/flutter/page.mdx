# Flutter SDK

The `gebeta_gl` plugin renders Gebeta vector tiles as a Flutter widget, natively on iOS and Android. Maps stay sharp at every zoom level, and you style them with a JSON style file you ship with your app.

## Install

```bash
flutter pub add gebeta_gl
```

You'll also need an API key from [Gebeta Maps](https://gebeta.app/) and a map style JSON file in your assets, such as `assets/styles/basic.json`. List it under `flutter: assets:` in `pubspec.yaml`.

## Show a map

The style file is loaded from your app bundle, so the widget waits for it before showing the map.

```dart
import 'package:flutter/material.dart';
import 'package:flutter/services.dart';
import 'package:gebeta_gl/gebeta_gl.dart';

class MapScreen extends StatelessWidget {
  const MapScreen({super.key});

  static const apiKey = '{your-api-key}';

  Future<String> loadMapStyle() => rootBundle.loadString('assets/styles/basic.json');

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: FutureBuilder<String>(
        future: loadMapStyle(),
        builder: (context, snapshot) {
          if (snapshot.hasError) {
            return const Center(child: Text('Could not load the map style'));
          }
          if (!snapshot.hasData) {
            return const Center(child: CircularProgressIndicator());
          }
          return GebetaMap(
            apiKey: apiKey,
            styleString: snapshot.data!,
            compassViewPosition: CompassViewPosition.topRight,
            initialCameraPosition: const CameraPosition(
              target: LatLng(9.0192, 38.7525),
              zoom: 10.0,
            ),
          );
        },
      ),
    );
  }
}
```

Unlike the JavaScript SDKs, `LatLng` takes latitude first.
