# JavaScript SDK

`@gebeta/js` puts a Gebeta map on any web page. It's built on MapLibre GL JS, so everything MapLibre can do is still available. Using React? See the [React SDK](/tiles/react).

## Create a map

```javascript
import { GebetaMaps } from "@gebeta/js";

const gebetaMap = new GebetaMaps({
  auth: { accessToken, refreshToken },
});

const map = gebetaMap.init({
  container: "map",
  center: [38.7685, 9.0161],
  zoom: 12,
  navigationControl: true,
});
```

| Option              | Description                                                      |
| ------------------- | ---------------------------------------------------------------- |
| `container`         | The ID of the element to draw the map in, or the element itself. |
| `center`            | Where the map starts, as `[lng, lat]`. Defaults to Addis Ababa.  |
| `zoom`              | The starting zoom level.                                         |
| `navigationControl` | Set `true` to show zoom and compass buttons.                     |
| `style`             | The map style. Defaults to the standard style.                   |

<Callout title="Longitude first">
  `center` is `[lng, lat]`, the MapLibre order. The routing APIs use `{lat,lng}`, so swap the values when you pass a route's points to the map.
</Callout>

## Change the style

```javascript
import { API } from "@gebeta/api";

gebetaMap.init({
  container: "map",
  style: API.Map.Constants.MAP_STYLES.SATELLITE,
});
```

The styles are `STANDARD` (the default), `SATELLITE` and `TERRAIN`.

## Use MapLibre directly

`getMap()` returns the underlying MapLibre map, so you can use any MapLibre GL JS API on it.

```javascript
const map = gebetaMap.getMap();

map.on("click", (event) => {
  console.log(event.lngLat);
});
```
