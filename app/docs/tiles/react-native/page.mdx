# React Native SDK

`@gebeta/tiles-react-native` brings Gebeta maps to iOS and Android apps built with React Native. Beyond showing the map, it covers markers, fences, paths and clustering, plus geocoding, directions and a full navigation screen.

## Show a map

```tsx
import { useRef } from "react";
import { Alert, View } from "react-native";
import { GebetaMap, GebetaMapRef } from "@gebeta/tiles-react-native";

export default function App() {
  const mapRef = useRef<GebetaMapRef>(null);

  const handleMapLoaded = () => {
    mapRef.current?.addImageMarker(
      [38.7463, 9.0223],
      "https://example.com/marker.png",
      [32, 32],
      () => Alert.alert("Marker clicked")
    );
  };

  return (
    <View style={{ flex: 1 }}>
      <GebetaMap
        ref={mapRef}
        apiKey="{your-api-key}"
        center={[38.7463, 9.0223]}
        zoom={12}
        onMapClick={([lng, lat]) =>
          Alert.alert("Map clicked", `${lat.toFixed(6)}, ${lng.toFixed(6)}`)
        }
        onMapLoaded={handleMapLoaded}
      />
    </View>
  );
}
```

`center` and the coordinates passed to `onMapClick` are `[lng, lat]`.

## Move the camera

`flyTo` animates the camera to a new place, zoom and tilt.

```tsx
mapRef.current?.flyTo({
  center: [37.3895, 11.5946],
  zoom: 14,
  pitch: 45,
  duration: 5000,
});
```

## Props

| Prop                | Type                                             | Required | Description                               |
| ------------------- | ------------------------------------------------ | -------- | ----------------------------------------- |
| `apiKey`            | `string`                                         | Yes      | Your Gebeta Maps API key.                 |
| `center`            | `[number, number]`                               | Yes      | Where the map starts, as `[lng, lat]`.    |
| `zoom`              | `number`                                         | Yes      | The starting zoom level.                  |
| `onMapClick`        | `(lngLat: [number, number], event: any) => void` | No       | Called when the map is tapped.            |
| `onMapLoaded`       | `() => void`                                     | No       | Called once the map has finished loading. |
| `blockInteractions` | `boolean`                                        | No       | Turn off panning, zooming and tapping.    |
| `style`             | `any`                                            | No       | Styles for the map container.             |
| `clusteringOptions` | `ClusteringOptions`                              | No       | How to cluster markers.                   |

Works on iOS and Android.
