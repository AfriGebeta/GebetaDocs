# React SDK

`@gebeta/react` wraps the [JavaScript SDK](/tiles/js) in a `GebetaMap` component. It creates the map when the component mounts and cleans it up when it unmounts, so you don't manage the map's lifecycle yourself.

## Show a map

```jsx
import { GebetaMap } from "@gebeta/react";

export function App() {
  return (
    <GebetaMap
      accessToken={accessToken}
      refreshToken={refreshToken}
      style={{ width: "100%", height: "400px" }}
    />
  );
}
```

Give the map a height, either through `style` or a parent element, or it renders with no height.

## Get the map instance

Pass `onReady` to get the `GebetaMaps` instance and its managers once the map has loaded. From there you can add markers or call `getMap()` for the underlying MapLibre map.

```jsx
<GebetaMap
  accessToken={accessToken}
  refreshToken={refreshToken}
  style={{ width: "100%", height: "400px" }}
  onReady={(gebetaMap) => {
    gebetaMap.getMap().flyTo({ center: [38.7685, 9.0161], zoom: 14 });
  }}
/>
```
